Project Title
Multi-Objective Traffic Signal Optimization Using Multi-Agent Reinforcement Learning
with ARIMA-Based Traffic Prediction in SUMO

1. INTRODUCTION
1.1 Purpose
This document specifies the complete functional and non-functional requirements for
implementing a multi-agent reinforcement learning (MARL) based traffic signal
optimization system integrated with:
●​ SUMO (Simulation of Urban Mobility)​
●​ ARIMA-based short-term traffic flow prediction​
●​ Multi-objective reward optimization (delay, fuel, emissions)​

The target of this specification is an AI software agent that will autonomously implement the
full system.

1.2 System Overview
The system shall:
1.​ Simulate an urban traffic network in SUMO.​
2.​ Assign one RL agent per signalized intersection.​
3.​ Predict short-term traffic inflow using ARIMA.​
4.​ Optimize signal timing policies via MARL.​
5.​ Minimize:​
○​ Total waiting time​

○​ CO2 emissions​
○​ Fuel consumption​
6.​ Support centralized training and decentralized execution.​

3.3 ARIMA Prediction Module
3.3.1 Purpose
Predict short-term vehicle inflow for each intersection.

3.3.2 Input
●​ Historical vehicle inflow time series per intersection.​

3.3.3 Model
ARIMA(p, d, q)
Initial configuration:
●​ p = 5​
●​ d = 1​
●​ q = 0​

3.3.4 Output
X^t+1:t+k\hat{X}_{t+1:t+k}X^t+1:t+k​

Predicted inflow for next k steps (default k = 5).

3.3.5 Integration
Predictions must be appended to the agent state vector.

3.4.2 Agents

●​ Each agent has independent observation.​
●​ Shared policy or individual policies configurable.​
